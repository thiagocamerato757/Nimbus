# Title profiles are hand-edited YAML, checked at load

The first release has no profile editor. Each Title has a rules file and a separate Character Catalog file (the catalog changes with every new Character, the rules rarely do), both validated when loaded.

- **Rules file:** stable id, display name and format version; display labels for Character and Character Pool; team size and optional Roles; the two Side names, a coupled flag and, if coupled, which Side picks first; default First Selection holder to pre-fill; named Draft Orders and a default; allowed Series Formats and a default; Fearless presets and a default; rule settings for banning a locked Character (allow, warn, reject), the same Character twice in a Game (allow, reject) and whether Voided Games count; default countdown seconds for ban and pick turns; the default number of Games a report covers; the clear-majority threshold for inferring a pick's Role ([ADR 0023](0023-pick-role-resolution.md)); the minimum sample size below which a statistic is low confidence, the game terms with digits allowed in report text ([ADR 0021](0021-numbers-are-code-interpretation-is-ai.md)); the rate change that counts as material for a saved report ([ADR 0025](0025-saved-reports-are-snapshots.md)); the shortlist's band thresholds ([ADR 0026](0026-copilot-shortlist-then-enrichment.md)); and, per language, the game terms left untranslated ([ADR 0024](0024-ai-output-in-english-or-portuguese.md)).
- **Catalog file:** each Character's stable id, display name, aliases and Retired flag. No roles or tags ([ADR 0017](0017-character-roles-derived-from-data.md)).

For rule settings, "reject" means an Override is needed, "warn" accepts with a notice and no Violation, and "allow" is silent. The timer only informs: running out never skips a turn or blocks entry.
