# Side and Draft Position are independent

Since LoL's First Selection rule, the blue side no longer implies first pick, so Side and Draft Position are separate attributes of a Team in a Game. Draft order is written in terms of the First-pick and Second-pick Team, never Sides, and the engine needs only Draft Position to validate turn order. Side is kept for scouting. A Title profile flag says whether the two are coupled, so older formats and other Titles still fit.
