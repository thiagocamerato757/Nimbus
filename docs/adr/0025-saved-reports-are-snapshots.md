# Saved Scouting Reports are snapshots

This is an explicit exception to [ADR 0008](0008-draft-state-derived-from-draft-actions.md): do not turn saved reports into live views. A report's Interpretations were written about particular numbers, so if the numbers moved underneath them the text could say the opposite of the data beside it.

- A saved report stores its scope, statistic values and sample sizes and the Games behind them with each Game's Source ([ADR 0027](0027-every-record-keeps-its-source.md)), and never changes by itself. Changing only its language keeps the same snapshot.
- It stores a data fingerprint and is outdated when the recomputed fingerprint differs, so detecting this does not need every statistic recomputed. The fingerprint covers Game ids and a version per Game; Player records; Declared Pools; statistic-related profile settings; name mappings and identity decisions (aliases, "same Game" and "same Player" answers), since a merge changes counts without touching a Game; Source kinds, since reclassifying changes the default scope; and a version of the statistics code, bumped whenever a computation changes. Over-flagging is harmless, because the per-Interpretation check shows what still holds.
- Staleness is also judged per Interpretation, marked "data has changed materially" (not "contradicted", since code cannot know the sentence is wrong) when any cited statistic: has a rate that moved by 20 percentage points or more (a profile setting); has a material ranking change, meaning the cited item left the rank band it was cited for (cited first, now third or lower) or the item now ahead leads it by more than one Game; crossed the low-confidence line either way; or no longer exists. The rest of the report stays valid.
- Refreshing creates a new version, keeps the old one and shows the statistics that changed most between them, since a shift in the opponent's behaviour is often the most useful finding.
- Statistics pages and the copilot always use live data. Saved Interpretations may be given to the copilot as background, labelled with their date and state; materially changed ones are excluded or clearly labelled.
